
# ☁️ Day 1 — Cloud Fundamentals + AWS Setup

> Building the foundation for the Cloud DevOps & SRE journey

---

## 📌 Introduction

Day 1 marks the beginning of my **20-Day Cloud DevOps & SRE Learning Journey**.

The objective of Day 1 is to build a strong understanding of **Cloud Computing and AWS fundamentals** before moving into infrastructure, networking, security, containers, CI/CD, Kubernetes, monitoring, and SRE concepts.

Instead of simply memorizing cloud terminology, this day focuses on understanding:

- Why cloud computing exists
- Problems with traditional infrastructure
- How cloud computing changes infrastructure management
- Public, private, and hybrid cloud
- IaaS, PaaS, and SaaS
- Why organizations use AWS
- AWS global infrastructure
- Regions and Availability Zones
- AWS account security
- AWS Management Console
- AWS CLI
- Basic AWS CLI operations

---

## 🎯 Day 1 Objectives

By the end of Day 1, I should be able to:

- Explain cloud computing in simple technical terms.
- Compare traditional/on-premises infrastructure with cloud computing.
- Differentiate public, private, and hybrid cloud.
- Explain IaaS, PaaS, and SaaS.
- Explain why organizations adopt cloud platforms.
- Explain why AWS is widely used.
- Understand AWS Regions and Availability Zones.
- Understand basic AWS account security practices.
- Install and use the AWS CLI.
- Authenticate the AWS CLI securely.
- Identify the AWS identity currently being used by the CLI.
- Explore AWS Regions and Availability Zones using the CLI.
- Explain the above concepts in an entry-level technical interview.
