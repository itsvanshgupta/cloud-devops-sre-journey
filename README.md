# ☁️ 20-Day Cloud DevOps & SRE Journey

> From Cloud & AWS Fundamentals to an Interview-Ready Entry-Level DevOps/SRE Engineer

---

## 👋 Introduction

Welcome to my **20-Day Cloud DevOps & SRE Learning Journey**.

This repository documents my structured progression from **beginner-level cloud knowledge to a practical, interview-focused foundation in Cloud, DevOps, and Site Reliability Engineering (SRE)**.

The goal of this journey is not simply to complete tutorials or memorize cloud services. Instead, I am focusing on understanding **why technologies exist, how they work, how engineers use them in real-world environments, how to troubleshoot failures, and how different DevOps technologies connect together**.

Throughout this journey, I will combine:

- 📚 Technical learning
- 🧪 Hands-on AWS labs
- 💻 Linux & scripting practice
- 🔧 DevOps tooling
- 🐳 Docker & containerization
- 🔄 CI/CD automation
- ☸️ Kubernetes fundamentals
- 📊 Monitoring & observability
- 🔐 Cloud security
- 🛡️ SRE & reliability concepts
- 🧠 Scenario-based troubleshooting
- 🎯 Interview preparation
- 📁 Technical documentation

---

## 🎯 Goal

My primary objective is to build a strong foundation for **entry-level Cloud DevOps / DevOps / SRE Engineer opportunities** and become capable of confidently discussing cloud infrastructure, automation, deployment, monitoring, security, reliability, and troubleshooting during technical interviews.
